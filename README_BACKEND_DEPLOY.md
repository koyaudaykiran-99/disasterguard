# AI-DisasterGuard — FastAPI Backend + Machine Learning

## How to Deploy to Render:
1. Push this folder to a GitHub repository.
2. Go to https://dashboard.render.com -> Click 'New +' -> 'Blueprint'.
3. Select the repository (render.yaml is already included).
4. Render will automatically create the PostgreSQL database with PostGIS and deploy FastAPI.
5. Once deployed, copy your backend URL and paste it as VITE_API_URL in the frontends!
